# Правила DeltaBilyard v1

Это явно заданный игровой вариант восьмёрки, а не заявление о полной сертификации WPA.

- 1×1: игрок сохраняет серию после правильного забития своего шара. После промаха ход переходит сопернику.
- 2×2: места А1, Б1, А2, Б2 в порядке входа. Успешно забивший продолжает серию. При смене команды её следующий заход выполняет другой партнёр.
- На разбое первым должен быть контакт с головным шаром №1. Требуется забить прицельный шар либо довести минимум четыре разных прицельных шара до борта.
- Восьмёрка на разбое приводит к новой расстановке; при фоле право разбоя передаётся сопернику с битком с руки. Шары на разбое не назначают группы.
- После разбоя первый правильно забитый прицельный шар определяет группу. При нескольких шарах — первый по времени попадания. На открытом столе нельзя первым касаться восьмёрки.
- После назначения группы первый контакт — свой шар; после забития всей группы — восьмёрка. После контакта требуется забитие или касание борта любым шаром.
- Биток в лузе, неправильный/отсутствующий первый контакт, отсутствие борта/забития и истечение времени — фол. Соперник получает биток с руки в любом свободном месте игрового поля вне луз.
- Забитые при фоле прицельные шары остаются в лузах. Забитие только чужого шара не сохраняет очередь.
- Для восьмёрки выбирается луза до удара. Законно забитая восьмёрка выигрывает партию. Ранняя восьмёрка, фол при её забитии или неверная луза — поражение.
- Матч идёт до выбранного числа побед (1, 3 или 5), не best-of. Разбой следующей партии последовательно переходит по местам.
- Длительность хода: 30/45/60 секунд. Движение шаров и общее окно повтора не расходуют время следующего игрока. Личный пропуск повтора не ускоряет начало следующего хода.
- Обрыв связи: до 60 секунд на возвращение, один раз на игрока за матч. Таймер прицеливания приостанавливается. Повторный обрыв после использованной паузы означает техническое поражение; выход из матча — также.
- Тренировка использует один профиль и те же физические правила, без соперника и таймера хода.
